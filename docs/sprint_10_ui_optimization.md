# Sprint 10: UI 与功能优化 (UI & Functionality Optimization)

**目标**: 聚焦于前端 UI 和功能的深度优化，重点提升文件管理的效率与体验，包括多选操作、文件预览以及桌面级的列表视图体验。

## 1. 多文件选择与并发操作
*   **功能描述**: 支持用户通过复选框、Shift/Ctrl + 点击等方式选择多个文件或文件夹，并支持对选中项进行批量操作（下载、删除、移动）。
*   **关键任务**:
    *   **状态管理**: 在 `useSelectionStore` 或组件内部状态中支持 `Set<string>` 类型的选中集合，处理全选/反选逻辑。
    *   **交互支持**: 为 `FileItem` 和 `BucketItem` 添加选中态样式；实现 Shift 范围选择和 Cmd/Ctrl 加选逻辑。
    *   **并发操作**:
        *   **批量下载**: 验证 SDK 是否支持并发流或打包下载；前端实现队列管理。
        *   **批量删除/移动**: 循环调用后端 API 或使用后端提供的批量接口（需确认 `internal/storage` 是否支持 `DeleteObjects` 等批量操作）。
    *   **UI 反馈**: 底部或顶部显示 “已选择 X 项”，提供批量操作工具栏。

## 2. 文件预览功能
*   **功能描述**: 补全缺失的文件预览能力，支持图片、文本、代码、PDF 等常见格式的快速预览。
*   **关键任务**:
    *   **预览模态框**: 创建 `FilePreviewModal` 组件，根据文件 MIME type 渲染不同内容。
    *   **内容获取**: 实现 `useFileContent` hook，对于文本/代码使用 `GetObject` 获取内容，对于图片使用 Blob URL。
    *   **集成**: 在文件列表的双击事件或右键菜单中触发预览。

## 3. 增强型列表视图 (Table View)
*   **功能描述**: 改造现有的 “列表模式” 为 “详细信息表格” 模式，效仿 Windows 资源管理器，直观展示文件大小、修改日期、类型等元数据，并支持列排序。
*   **技术选型**:
    *   **核心逻辑**: 使用 **TanStack Table (React Table)** 处理数据绑定、排序 (Sorting)、筛选 (Filtering) 和行选择 (Row Selection) 逻辑。
    *   **UI 组件**: 使用 **Shadcn UI** 的 Table 组件进行渲染，保持设计风格统一。
*   **关键任务**:
    *   **组件开发**: 新增 `FileTable` 组件，替代原有的简单列表渲染。
    *   **列定义**: 定义 `columns` (Name, Size, Type, Date Modified, Actions)。
    *   **交互**: 实现点击表头排序，点击行选中，双击行进入/预览。
    *   **数据格式化**: 统一优化 `formatSize` 和 `formatDate` 显示。

## 验收标准
- [x] 用户可以使用 Shift/Ctrl 键进行多文件选择，选中文样式清晰。
- [x] 选中多个文件后，可以成功触发批量删除和批量下载（如不支持打包则分个下载）。
- [x] 图片、文本文件可以正常预览，不支持的格式显示友好的占位提示。
- [x] 列表视图成功升级为表格视图，支持按大小、时间排序，列宽适配良好。
