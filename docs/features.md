## 一、连接与账户管理

### 1.1 多账户配置
- 支持添加、编辑、删除多个存储账户配置
- 每个账户需包含：
  - 账户名称（自定义）
  - 服务商类型（AWS S3 / 阿里云 OSS / 腾讯云 COS / Cloudflare R2）
  - Endpoint（访问地址）
  - Access Key ID
  - Secret Access Key
  - 默认区域（Region）
  - 是否使用 SSL
  - 自定义端口（可选）
- 账户配置本地加密存储
- 支持账户配置的导入/导出（加密格式）
- 快速切换账户（下拉菜单或侧边栏）
- 测试连接功能（验证配置是否正确）

### 1.2 会话管理
- 记住上次使用的账户
- 支持同时打开多个账户的标签页/窗口
- 会话超时自动断开提醒

## 二、存储桶（Bucket）管理

### 2.1 存储桶浏览
- 存储桶以"磁盘"形式展示在统一文件浏览器根目录
- 点击存储桶进入对象浏览（如同进入本地磁盘）
- 显示存储桶基本信息：
  - 名称
  - 区域
  - 创建时间
  - 对象数量（如果可获取）
  - 总容量（如果可获取）
- 搜索/过滤存储桶

### 2.2 存储桶操作
- 通过右键菜单或工具栏新建存储桶
  - 指定名称
  - 选择区域
  - 设置访问权限（私有/公共读等）
  - **【OSS 特有】** 存储类型选择（标准/低频/归档等）
  - **【COS 特有】** 多 AZ 配置选项
- 右键菜单删除存储桶（需确认，检查是否为空）
- 右键菜单进入存储桶设置
- 刷新存储桶列表

### 2.3 存储桶属性配置
- 查看和编辑存储桶属性：
  - 版本控制（启用/暂停）
  - 加密设置（服务端加密）
  - 标签管理
  - 生命周期规则
  - 跨域资源共享（CORS）配置
  - [x] 静态网站托管设置
  - [x] 日志记录配置
  - **【AWS 特有】** S3 事件通知
  - **【OSS 特有】** 传输加速
  - **【COS 特有】** 回源设置
  - **【R2 特有】** 自定义域名绑定

> 能力说明：目前仅 AWS 账户可在 CAN 内直接配置版本控制、默认加密、生命周期、CORS、静态网站与 Bucket Policy。其它供应商会在界面中自动隐藏或禁用相关入口，并在后端返回“供应商暂不支持”的提示，避免误操作。

### 2.4 访问控制
- [x] 存储桶策略（Bucket Policy）编辑
- ACL（访问控制列表）管理
- **【AWS/OSS 特有】** 阻止公共访问设置
- **【OSS 特有】** 防盗链设置

## 三、对象（Object）浏览与管理

- 网格视图 / 列表视图切换
- 显示文件信息：
  - 文件名
  - 大小
  - 类型
  - 最后修改时间
  - 存储类型
  - ETag
- 路径快速跳转（返回按钮、面包屑点击）

## 云服务商特有功能标识说明

在实现时，对于特定云服务商的独有功能，建议采用以下标识方式：

1. **图标标识**：在功能入口处显示对应云服务商的 Logo 或特殊图标
2. **文字标签**：使用如 `[AWS Only]`、`[阿里云专属]`、`[腾讯云独有]`、`[R2 特性]` 等标签
3. **颜色区分**：使用不同的背景色或边框色区分通用功能和特定功能
4. **动态显示**：切换到不支持该功能的云服务商时，自动隐藏或置灰相关选项
5. **提示说明**：鼠标悬停时显示 Tooltip，说明该功能的适用范围

这样可以确保用户在使用不同云服务商时，能够清晰地了解哪些功能可用，哪些是特定平台的增强功能。
