# Sprint Plan（2025 Q1）

> 目标：针对当前尚未实现的能力拆分三个互不阻塞的 Sprint，分别覆盖对象操作、下载分享以及安全合规方向。所列范围均来源于 `docs/spec` 中尚未勾选的条目。

## Sprint 1 — 对象操作与元数据中心

- **关联 Spec**：`object_basic_operations.md`、`object_properties_metadata.md`、`batch_operations.md`
- **目标**：补齐复制/移动/重命名/新建目录、元数据/标签/ACL 编辑，以及批量操作体验，使文件浏览器真正具备数据运维能力。
- **范围**：
  1. 「多选 + 批量操作」：在 `FileExplorer` 增加多选状态、工具栏/右键批量入口，并接入 `searchStore`/`objectsStore` 的选中集合。
  2. 「复制/移动/重命名」：串联后端 CopyObject/MoveObject/重命名 API，提供批量确认对话框与冲突策略（覆盖/重命名/跳过）。
  3. 「虚拟目录创建」：支持前缀占位文件(`key/`)创建、重复校验与目录快捷操作。
  4. 「对象详情与元数据」：新增右侧抽屉或对话框，接入 HeadObject，展示并编辑 Metadata、标签、存储类型、ACL，含版本历史与恢复入口。
  5. 「批量属性写入」：对多选集合执行批量标签/ACL/存储类型修改，提供进度追踪与失败重试。
- **交付物**：
  - `objectsStore` 与新建 `objectActionsStore`（或 zustand slice）的 API 封装及单元测试。
  - 可访问的 UI（面包屑旁批量工具栏、详情抽屉等）及 E2E/单测。
  - 更新后的 spec 截图/说明及 release note。
- **并行性说明**：主要围绕对象浏览区域，既不触及传输栈也不改动安全、下载逻辑，可独立推进。
- **风险/依赖**：
  - Copy/Move API 需要统一 supplier 行为（ACL、版本）；如后端尚未暴露需排期。
  - 批量操作在海量对象场景下需分批/异步，需设计任务调度与提示。

## Sprint 2 — 下载体验与分享链接增强

- **关联 Spec**：`file_download.md`、`object_access_link_generation.md`
- **目标**：把当前的单文件下载与简单预签名复制升级为完整的下载队列 + 可配置分享体验，覆盖批量压缩、断点续传、二维码等需求。
- **范围**：
  1. 「下载队列管理」：复用/拓展 `transfersStore`，为下载任务提供排队、暂停/恢复/取消、进度与限速；支持应用重启后的任务恢复。
  2. 「批量/文件夹下载」：后端提供打包 ZIP（或串行下载并自动解压），前端可在多选后触发下载任务。
  3. 「断点续传 & 重试」：下载任务保存 Range 进度，网络中断后可继续；提供自动重试策略与错误提示。
  4. 「预签名链接面板」：新增配置模态（过期时间、HTTP 方法、响应头、自定义文件名），生成 URL/Markdown/HTML 三种格式，一键复制。
  5. 「二维码 & 历史」：集成二维码库，支持链接历史记录、快速复制与失效提示。
  6. 「安全提示」：链接生成时校验对象访问策略，若桶为私有则展示过期提醒。
- **交付物**：
  - 新的下载任务 API（后端）与前端 store 扩展、组件（下载抽屉/表格）。
  - 预签名配置模态、二维码组件、历史列表，以及相应的单元测试。
  - 文档/帮助中心更新，说明如何批量下载与分享。
- **并行性说明**：下载/分享逻辑集中在传输与对象右键菜单部分，不影响 Sprint 1 的对象写操作，也不与 Sprint 3 的安全表单重叠。
- **风险/依赖**：
  - ZIP 打包和并发下载需要考虑大文件内存占用，可优先实现服务器端流式压缩。
  - 跨平台下载路径/权限差异需测试（Windows/Mac/Linux）。

## Sprint 3 — 安全合规与会话治理

- **关联 Spec**：`access_control_security.md`、`session_management.md`、`help_support.md`（审计日志片段）
- **目标**：完善安全基线，提供 IAM/STS 支持、桶 ACL/阻止公共访问配置、合规检测、审计日志以及会话管理。
- **范围**：
  1. 「会话管理」：实现会话超时检测、活跃标签同步、超时提醒与重新登录流程；记录最近使用账户与标签页状态。
  2. 「安全配置面板」：在 Bucket 设置或独立安全页中加入 ACL、Block Public Access、MFA Delete 提示、默认加密状态展示。
  3. 「STS & 凭证策略」：允许用户生成临时凭证，提供最小权限指导/模板，并在账户表单中显示安全建议。
  4. 「合规性检查」：实现自动扫描（版本控制、加密、日志等），输出检查列表、一键跳转到对应设置并可导出报告。
  5. 「审计日志 & 报告」：记录敏感操作（登录、删除、权限修改），提供筛选/导出，并与帮助中心/文档联动。
- **交付物**：
  - 新的安全 store/API，UI 面板、日志 Viewer，以及对应的后端 handler/数据库结构。
  - Session 管理 hook（前端）与超时策略配置。
  - 合规扫描脚本与报告模板（CSV/PDF）。
- **并行性说明**：聚焦安全/会话模块，主要触及账户/设置场景，可与对象操作、下载链路并行开发。
- **风险/依赖**：
  - 需评估各云厂商 API 覆盖度（如 Block Public Access、STS），必要时做 Provider Capability 回退。
  - 审计日志可能引入新的持久层或影响性能，需提前设计批量写入策略。
