# 对象基础操作

## 功能描述
提供文件/文件夹的基础操作，包括复制、移动、重命名、删除、新建文件夹和在线预览/编辑等。

## 核心需求

### 1. 文件复制
- 选择源文件/文件夹
- 选择目标位置（同桶或跨桶）
- 支持批量复制
- 处理重名文件（覆盖/保留/重命名）
- 复制时保留元数据和标签
- 显示复制进度（大文件时）

### 2. 文件移动
- 选择源文件/文件夹
- 选择目标位置（同桶或跨桶）
- 支持批量移动
- 处理重名文件（覆盖/保留/重命名）
- 移动后自动刷新界面

### 3. 文件重命名
- 编辑文件名
- 验证新文件名有效性
- 处理重名情况
- 通过复制+删除或直接API实现（取决于服务商支持）

### 4. 文件删除
- 支持单个删除
- 支持批量删除
- 显示删除确认对话框
- 检查版本控制（删除单个版本或所有版本）
- 显示删除进度（大量文件时）
- 删除完成后刷新界面

### 5. 创建文件夹（虚拟目录）
- 输入文件夹名称
- 在当前目录创建前缀
- 处理重名文件夹
- 支持嵌套创建

### 6. 文件预览
支持以下文件类型的在线预览：
- **图片**：JPG、PNG、GIF、WebP等（显示缩略图和全分辨率）
- **文本**：TXT、JSON、XML、CSV等（语法高亮）
- **视频**：MP4、WebM等（集成视频播放器）
- **音频**：MP3、WAV等（集成音频播放器）
- **PDF**：PDF文档（集成PDF查看器）
- 不支持的格式提示用户下载

### 7. 在线编辑文本文件
- 提供在线编辑器（支持多种语言语法高亮）
- 编辑保存（上传更新）
- 编辑前后对比（可选）
- 撤销/重做功能
- 自动保存或手动保存

### 8. 刷新当前目录
- 重新加载当前目录的文件列表
- 更新文件信息

## 数据流
1. 用户选择操作（复制/移动/删除等）
2. 显示操作对话框/确认信息
3. 调用相应S3 API或组合调用
4. 更新UI（刷新列表或显示进度）
5. 操作完成反馈
