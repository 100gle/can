# 对象浏览

## 功能描述
提供统一的文件系统浏览体验，将存储桶和对象浏览合并为类似本地文件管理器的界面，支持树形导航、视图切换、右键菜单操作等功能。

## 核心需求

### 1. 统一文件浏览器（FileExplorer）
- **根目录显示存储桶列表**：进入账户后首先看到所有存储桶
- **点击存储桶进入对象浏览**：如同进入本地磁盘一样
- **层级导航**：根目录 → 存储桶 → 文件夹 → 子目录
- 支持目录展开/折叠
- 显示目录图标和文件类型图标
- 支持递归加载目录内容

### 2. 视图模式切换
- **网格视图（Grid）**：卡片形式显示，适合快速浏览
  - 存储桶显示硬盘图标
  - 文件夹显示文件夹图标
  - 文件根据类型显示不同图标（图片、文档、代码、压缩包等）
- **列表视图（List）**：表格形式显示文件详情
- 记住用户选择的视图模式

### 3. 文件信息展示
展示以下信息：
- 文件名
- 文件大小（格式化显示，如KB、MB、GB）
- 文件类型（根据扩展名识别）
- 最后修改时间
- 存储类型（标准、低频、归档等）
- ETag（文件指纹）

### 4. 面包屑导航
- 显示完整的导航路径：`根目录 / bucket-name / folder / subfolder`
- 支持点击面包屑快速跳转到任意层级
- 根路径显示"根目录"

### 5. 内联搜索与过滤
- **搜索框**：实时搜索当前目录下的文件
- **类型过滤**：按文件类型快速筛选
  - 全部
  - 文件夹
  - 图片
  - 文档
  - 压缩包
- **清除过滤**：一键清除所有过滤条件

### 6. 右键上下文菜单
**存储桶右键菜单**：
- 进入
- 设置
- 删除

**对象/文件右键菜单**：
- 下载
- 复制链接
- 分享（预签名 URL）
- 删除

**文件夹右键菜单**：
- 进入
- 删除

**空白区域右键菜单**：
- 新建存储桶（仅在根目录）
- 上传文件
- 上传文件夹
- 刷新

### 7. 拖拽上传
- 支持拖拽文件到浏览区域上传
- 显示拖拽高亮状态
- 支持多文件和文件夹拖拽

### 8. 分页与加载
- 对象列表分页加载（通过 "加载更多" 按钮）
- 显示加载状态
- 支持S3分页标记（continuation token）

## 数据获取
- 存储桶列表：使用 S3 ListBuckets API
- 对象列表：使用 S3 ListObjects/ListObjectsV2 API
- 分页获取数据
- 支持前缀过滤
