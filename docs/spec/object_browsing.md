# 对象浏览

## 功能描述
提供灵活的文件浏览方式，包括树形目录、列表/网格视图切换、搜索等功能。

## 核心需求

### 1. 树形目录结构
- 基于对象Key的前缀模拟文件夹结构
- 支持目录展开/折叠
- 显示目录图标和文件图标
- 支持递归加载目录内容
- 处理嵌套目录深度

### 2. 视图模式切换
- **列表视图**：表格形式显示文件详情
- **网格视图**：卡片形式显示文件（预览缩略图）
- 记住用户选择的视图模式

### 3. 文件信息展示
展示以下信息列：
- 文件名
- 文件大小（格式化显示，如KB、MB、GB）
- 文件类型（根据扩展名识别）
- 最后修改时间
- 存储类型（标准、低频、归档等）
- ETag（文件指纹）
- 访问权限（ACL）

### 4. 面包屑导航
- 显示当前路径的面包屑
- 支持点击面包屑快速跳转到任意目录
- 根路径显示桶名

### 5. 路径快速跳转
- 路径输入框/地址栏
- 支持手动输入路径并跳转
- 路径自动完成（可选）

### 6. 搜索功能
- **前缀搜索**：按对象Key前缀搜索
- **全文搜索**（如果服务商支持）：搜索元数据
- 搜索框在当前路径或全桶范围
- 显示搜索结果

### 7. 文件排序
支持排序维度：
- 文件名（A-Z或Z-A）
- 文件大小（大到小或小到大）
- 修改时间（新到旧或旧到新）
- 文件类型

### 8. 多选操作
- 支持多选文件/文件夹
- 全选/反选功能
- 显示已选文件数量
- 根据选择启用/禁用操作按钮

### 9. 加载和分页
- 对象列表分页加载（1000条/页或可配置）
- 显示加载状态
- 支持虚拟滚动优化性能（大量文件时）

## 数据获取
- 使用S3 ListObjects/ListObjectsV2 API获取对象列表
- 分页获取数据
- 支持前缀过滤
