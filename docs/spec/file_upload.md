# 文件上传

## 功能描述
支持多种上传方式，包括拖拽上传、文件夹上传、断点续传、批量上传等，并提供上传队列和进度管理。

## 核心需求

### 1. 上传方式
- **拖拽上传**：直接拖拽文件到指定区域上传
- **点击选择上传**：点击按钮打开文件选择对话框
- **文件夹上传**：选择文件夹并保持目录结构
- **批量上传**：同时上传多个文件

### 2. 断点续传
- 将文件分片上传（默认分片大小5MB，可配置）
- 记录已上传分片信息
- 支持暂停和恢复上传
- 上传中断后可续传（不需重新上传）
- 本地存储分片进度

### 3. 上传队列管理
- 维护上传任务队列
- 并发上传控制（默认并发数，可配置）
- 显示队列中各任务的状态
- 支持调整队列顺序（可选）
- 队列持久化（应用关闭后恢复）

### 4. 上传进度显示
- 总体上传进度条
- 单个文件上传进度
- 上传速度显示（KB/s或MB/s）
- 预计剩余时间
- 已上传/总大小显示

### 5. 上传失败处理
- 显示失败原因
- 提供重试按钮
- 自动重试机制（可配置重试次数和延迟）
- 记录失败日志

### 6. 上传参数配置
用户可在上传时设置以下参数：

**基础参数**：
- 存储类型（标准/低频/归档等，如服务商支持）
- 访问权限（私有/公共读等）
- 内容类型（Content-Type）

**高级参数**：
- 元数据（自定义Metadata Key-Value对）
- 缓存控制（Cache-Control header）
- 加密选项（SSE-S3/SSE-KMS等）

### 7. 文件夹上传
- 保持原目录结构
- 创建虚拟目录（前缀）
- 支持空目录处理

### 8. 上传预检
- 检查文件大小限制（如有）
- 验证文件类型限制（如有）
- 检查存储空间可用性
- 提示覆盖确认（文件已存在时）

## 数据流
1. 用户选择/拖拽文件
2. 验证文件和参数
3. 添加到上传队列
4. 分片处理（如启用断点续传）
5. 上传分片/整体文件
6. 更新进度
7. 处理完成或失败
