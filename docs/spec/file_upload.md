# 文件上传

## 功能描述
支持多种上传方式，包括拖拽上传、文件夹上传、断点续传、批量上传等，并提供上传队列和进度管理。

## 核心需求

### 1. 上传方式
- **拖拽上传**：
  - 支持文件和**文件夹**的拖拽，桌面端由 `DropOverlay`/`useFileDrop` 捕获系统级文件路径，Web 端由 `FileExplorer` 的拖拽区域接管。
  - 释放后即刻进入传输队列，不再弹出确认模态；队列中可随时暂停/取消。
  - 拖拽期间展示半透明高亮覆盖层，提示“Drop to Upload”。
- **点击选择上传**：点击按钮打开文件选择对话框。
- **文件夹上传**：选择文件夹并保持目录结构。
- **批量上传**：同时上传多个文件。

### 1a. 并发控制
- **文件夹上传并发**：对于包含大量文件的文件夹上传，必须实现并发控制（Concurrency Control）。
- **配置**：支持设置最大同时上传文件数（例如 5-10），避免一次性创建过多 HTTP 请求导致网络拥塞或触发服务商限流。
- **队列机制**：文件夹内的文件应被展平加入传输队列，由全局队列管理器统一调度，而非独立的并在任务。

### 2. 断点续传
- 将文件分片上传（默认分片大小5MB，可配置）
- 记录已上传分片信息
- 支持暂停和恢复上传
- 上传中断后可续传（不需重新上传）
- 本地存储分片进度

### 3. 上传队列管理
- 维护上传任务队列
- 并发上传控制（默认并发数，可配置）
- 显示队列中各任务的状态
- 支持调整队列顺序（可选）
- 队列持久化（应用关闭后恢复）

### 4. 上传进度显示
- 总体上传进度条
- 单个文件上传进度
- 上传速度显示（KB/s或MB/s）
- 预计剩余时间
- 已上传/总大小显示

### 5. 上传失败处理
- 显示失败原因
- 提供重试按钮
- 自动重试机制（可配置重试次数和延迟）
- 记录失败日志

### 6. 上传参数配置
用户可在上传时设置以下参数：

**基础参数**：
- 存储类型（标准/低频/归档等，如服务商支持）
- 访问权限（私有/公共读等）
- 内容类型（Content-Type）

**高级参数**：
- 元数据（自定义Metadata Key-Value对）
- 缓存控制（Cache-Control header）
- 加密选项（SSE-S3/SSE-KMS等）

### 7. 文件夹上传
- 保持原目录结构
- 创建虚拟目录（前缀）
- 支持空目录处理

### 8. 上传预检
- 检查文件大小限制（如有）
- 验证文件类型限制（如有）
- 检查存储空间可用性
- 提示覆盖确认（文件已存在时）

## 数据流
1. 用户选择/拖拽文件
2. 验证文件和参数
3. 添加到上传队列
4. 分片处理（如启用断点续传）
5. 上传分片/整体文件
6. 更新进度
7. 处理完成或失败
