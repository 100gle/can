# 同步功能

## 功能描述
支持本地文件夹与S3存储桶的双向同步，包括同步规则、定时任务和日志记录。

## 核心需求

### 1. 同步方向
- **单向同步**：本地→云存储或云存储→本地
- **双向同步**：本地和云存储互相同步（冲突解决策略）

### 2. 同步源和目标配置
**本地文件夹**：
- 选择要同步的本地文件夹路径
- 显示文件夹大小和文件数量

**云存储**：
- 选择目标S3桶
- 选择目标前缀/路径（可选）

### 3. 同步规则配置
支持以下规则：

**文件类型过滤**：
- 包含特定文件类型（如*.jpg、*.pdf等）
- 排除特定文件类型
- 使用通配符或正则表达式

**文件大小限制**：
- 排除超过指定大小的文件
- 排除小于指定大小的文件

**路径过滤**：
- 排除特定目录（如node_modules、.git等）
- 包含特定目录

**时间过滤**：
- 仅同步最近修改的文件
- 排除指定日期之前的文件

### 4. 增量同步
- 首次同步：传输全部文件
- 后续同步：仅传输新增或修改的文件
- 记录同步时间戳用于判断变更
- 支持增量同步和全量重新同步选择

### 5. 冲突解决策略（双向同步时）
- **保留本地版本**：本地文件覆盖云存储
- **保留云版本**：云存储文件覆盖本地
- **保留两个版本**：重命名其中一个
- **跳过冲突**：保留两个版本不覆盖
- **按修改时间解决**：保留最新修改版本
- **自定义脚本**（高级）：用户定义冲突解决逻辑

### 6. 删除策略
- **同时删除**：一端删除文件时同时删除另一端
- **仅备份**：删除时不影响另一端
- **保留历史版本**：删除时保存到特定目录
- **回收站**：先移到回收站，定期清理

### 7. 定时同步任务
- 创建定时同步任务
- 配置任务参数：
  - 同步规则和策略
  - 执行频率（每小时/每天/每周等）
  - 执行时间（如每天凌晨2点）
  - 是否在网络空闲时执行
  - 最大并发数
  - 失败重试策略
- 启用/禁用任务
- 查看任务详情
- 编辑任务配置
- 删除任务
- 手动立即执行任务

### 8. 同步前数据对比
- 显示将要同步的文件列表
- 显示新增/修改/删除的文件
- 显示同步大小预估
- 预览冲突情况（双向同步时）
- 用户可预览后再确认执行

### 9. 同步日志
记录每次同步操作：
- 同步时间
- 同步任务ID
- 同步方向
- 同步文件统计（新增/修改/删除数量）
- 总传输数据量
- 耗时
- 同步状态（成功/部分成功/失败）
- 错误详情

**日志查看**：
- 过滤日志（按时间、任务、状态等）
- 导出日志（CSV/JSON格式）
- 删除日志（可选）

### 10. 同步监控
- 显示正在执行的同步任务进度
- 显示同步统计（本次同步：新增xx，修改xx，删除xx）
- 实时速度显示
- 支持暂停同步
- 支持取消同步（清理临时文件）

## 数据流
1. 用户创建/配置同步任务
2. 设置同步规则和策略
3. 预览同步内容
4. 确认并执行同步
5. 实时显示同步进度
6. 同步完成后显示统计和日志
