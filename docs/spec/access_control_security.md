# 访问控制与安全

## 功能描述
实现IAM用户管理、STS临时凭证支持、数据保护配置和合规性检查等安全相关功能。

## 核心需求

### 1. IAM用户管理
**仅适用于AWS S3和部分云服务商**：

**功能**：
- 列出IAM用户（如支持）
- 创建IAM用户
- 修改用户权限
- 删除用户
- 生成访问密钥
- 禁用/启用访问密钥

**权限管理**：
- 显示用户当前权限
- 编辑权限策略
- 查看权限文档
- 一键应用最小权限策略建议

### 2. STS临时凭证支持
**功能**：
- 生成临时凭证（STS AssumeRole）
- 配置临时凭证有效期
- 设置临时凭证权限边界
- 使用临时凭证连接（而不存储永久凭证）
- 查看临时凭证状态

**优势**：
- 提高安全性（无需长期密钥）
- 支持跨账户访问
- 权限更细粒度控制

### 3. 最小权限原则提示
- 扫描当前账户/用户的权限
- 识别过度授予的权限
- 提供权限优化建议
- 示例：
  - "当前用户具有S3:*权限，建议限制为仅需的操作"
  - "未使用的权限：删除s3:DeleteBucket"

### 4. 数据加密状态显示
显示各项加密配置：

**存储加密**：
- 服务端加密状态（SSE-S3/SSE-KMS）
- 使用的KMS密钥
- 默认加密规则

**传输加密**：
- SSL/TLS支持
- 强制HTTPS标识

**客户端加密**（可选）：
- 支持本地加密再上传

**显示形式**：
- 仪表板：各桶的加密状态概览
- 详情：单个桶的加密详细配置

### 5. 版本控制状态监控
- 显示各桶的版本控制状态
- 已启用：显示版本保留策略
- 暂停：提示可以继续创建新版本
- 提示建议：
  - "建议启用版本控制以防意外删除"
  - "版本控制增加存储成本，建议配置生命周期规则自动删除旧版本"

### 6. MFA Delete配置提示
**仅AWS S3支持**：
- 显示MFA Delete状态
- 提示启用MFA Delete的益处：
  - "启用MFA Delete可防止未授权删除版本化对象"
  - "删除对象版本时需要提供MFA设备信息"
- 提供启用步骤或按钮

### 7. 合规性检查工具
提供自动检查工具，审查安全配置：

**检查项**：
1. 存储桶ACL检查
   - 提示公开读写风险
   - 建议：设置为Private

2. Bucket Policy检查
   - 识别允许匿名访问的策略
   - 提示：通常不安全

3. 版本控制检查
   - 建议启用版本控制（防止意外删除）
   - 成本影响提示

4. 加密检查
   - 检查是否启用服务端加密
   - 建议使用KMS加密而不是SSE-S3

5. 日志记录检查
   - 建议启用访问日志
   - 建议启用请求日志（CloudTrail）

6. MFA Delete检查（AWS）
   - 建议启用MFA Delete

7. 公共访问阻止检查
   - 建议启用"Block Public Access"设置

8. 防盗链检查（OSS）
   - 建议启用防盗链保护

**检查结果显示**：
- 问题等级：Critical（红色）/ Warning（黄色）/ Info（蓝色）
- 详细说明和修复建议
- 一键修复（如可能）

### 8. 操作日志记录
记录所有操作：
- 操作时间
- 操作类型（上传/删除/修改权限等）
- 操作用户/IP
- 操作对象（文件/桶等）
- 操作结果（成功/失败）
- 失败原因（如有）

**日志查看**：
- 过滤和搜索日志
- 导出日志（CSV/JSON）

### 9. 登录历史
- 记录账户登录事件
- 显示登录IP和时间
- 异常登录告警
- 禁用异常登录

### 10. 导出审计报告
- 生成安全审计报告
- 包含：合规性检查结果、权限分析、操作日志摘要等
- 导出格式：PDF/Excel
- 支持邮件发送

## 安全最佳实践提示
在UI中显示安全建议：
1. "定期轮换Access Key"
2. "使用STS临时凭证替代长期密钥"
3. "启用MFA验证"
4. "应用最小权限原则"
5. "启用版本控制"
6. "启用访问日志"
7. "定期审查权限配置"
