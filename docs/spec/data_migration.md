# 数据迁移

## 功能描述
支持跨账户和跨服务商的数据迁移，包括迁移进度跟踪、数据对比和校验等功能。

## 核心需求

### 1. 迁移场景支持
- **跨账户迁移**：同一云服务商不同账户之间的数据迁移
- **跨服务商迁移**：AWS S3 ↔ 阿里云OSS ↔ 腾讯云COS ↔ Cloudflare R2等

### 2. 迁移配置
**源配置**：
- 选择源账户和源桶
- 选择源前缀（可选，迁移子目录）
- 可选：选择特定时间范围的文件

**目标配置**：
- 选择目标账户和目标桶
- 设置目标前缀（可选）
- 选择目标存储类型（可与源不同）
- 选择目标访问权限

### 3. 迁移前数据对比
- 扫描源和目标
- 对比已有文件：
  - 源有目标无：待迁移
  - 源无目标有：处理选项（保留/删除）
  - 源目标都有：根据修改时间判断是否需要更新
- 显示对比结果统计：
  - 待迁移文件数量和总大小
  - 冲突文件数量
  - 预估迁移时间

### 4. 冲突处理策略
- **跳过**：目标已存在相同文件，不覆盖
- **覆盖**：无条件覆盖目标文件
- **按修改时间**：保留最新修改的文件
- **重命名**：为新文件添加后缀以避免覆盖

### 5. 迁移选项
- **保留源文件**：迁移后不删除源文件（默认）
- **迁移后删除源**：迁移完成后删除源文件
- **迁移元数据**：包括标签、自定义元数据等
- **迁移权限**：包括ACL和权限配置
- **保持目录结构**：保持原有目录层级

### 6. 性能配置
- **并发数**：同时传输的文件数量
- **分片大小**：大文件分片大小
- **速度限制**：带宽限制（可选）
- **重试策略**：失败重试次数和延迟

### 7. 迁移进度跟踪
**进度显示**：
- 总体进度条（已完成/总数，百分比）
- 传输速度（MB/s）
- 预计剩余时间
- 已迁移文件数和字节数
- 成功/失败/跳过计数

**实时更新**：
- 每个文件迁移完成时更新
- 显示当前正在迁移的文件名
- 显示错误提示（如有）

### 8. 迁移后数据校验
**校验方式**：
- **文件数量对比**：源和目标文件数是否一致
- **总大小对比**：源和目标总大小是否一致
- **ETag校验**：逐个文件校验ETag（同一服务商）
- **内容哈希校验**：计算MD5/SHA256校验（跨服务商）

**校验结果**：
- 显示校验进度
- 列出不一致的文件
- 报告校验结果（成功/失败）
- 支持重新校验

### 9. 迁移日志
记录迁移操作：
- 迁移ID和名称
- 源和目标信息
- 开始和结束时间
- 迁移统计（总数、成功、失败、跳过）
- 总传输数据量
- 失败文件列表和原因
- 校验结果

**日志管理**：
- 查看历史迁移记录
- 导出迁移日志（CSV/JSON）
- 按状态/时间过滤日志
- 支持重新执行失败项目

### 10. 暂停/恢复/取消
- **暂停迁移**：暂停正在进行的迁移
- **恢复迁移**：从暂停位置继续迁移
- **取消迁移**：停止迁移（可选择清理目标数据）

### 11. 增量迁移
- 支持首次全量迁移后的增量迁移
- 记录上次迁移时间
- 仅迁移新增或修改的文件
- 支持定期增量迁移

## 数据流
1. 用户选择源和目标
2. 系统进行数据对比
3. 用户配置迁移参数和策略
4. 预览迁移内容（可选）
5. 确认后开始迁移
6. 实时显示进度
7. 迁移完成后进行数据校验
8. 显示迁移结果和日志
