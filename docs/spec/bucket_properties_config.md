# 存储桶属性配置

## 功能描述
查看和编辑存储桶的各种属性配置，包括版本控制、加密、标签、生命周期等。

## 核心需求

### 1. 版本控制配置
- 查看版本控制状态（启用/暂停）
- 启用版本控制
- 暂停版本控制
- 显示版本控制启用时间

### 2. 加密设置
- 查看是否启用服务端加密
- 配置加密算法（SSE-S3/SSE-KMS等）
- **AWS特有**：KMS密钥选择
- 设置默认加密

### 3. 标签管理
- 查看现有标签列表
- 添加新标签（Key-Value对）
- 编辑标签
- 删除标签

### 4. 生命周期规则
- 查看现有生命周期规则列表
- 创建新规则：
  - 规则名称
  - 应用对象前缀
  - 规则状态（启用/禁用）
  - 转换策略（如转移到低频存储）
  - 过期策略（删除对象或删除版本）
  - 天数配置
- 编辑规则
- 删除规则

### 5. CORS配置
- 查看CORS规则列表
- 添加CORS规则：
  - 允许的Origins（来源）
  - 允许的Methods（GET/POST/PUT等）
  - 允许的Headers
  - 公开的Headers
  - Max Age Seconds
- 编辑规则
- 删除规则

### 6. 静态网站托管
- 查看是否启用静态网站托管
- 启用/禁用静态网站托管
- 配置索引文档（通常为index.html）
- 配置错误文档（404.html等）
- 获取网站访问URL

### 7. 日志记录配置
- 查看日志状态
- 启用/禁用访问日志
- 配置日志目标桶
- 配置日志前缀
- 日志保留策略

### 8. AWS特有功能
- **S3事件通知**：
  - 配置事件类型（Put、Delete等）
  - 配置通知目标（SNS、SQS、Lambda等）

### 9. 阿里云OSS特有功能
- **传输加速**：启用/禁用传输加速，显示加速域名

### 10. 腾讯云COS特有功能
- **回源设置**：
  - 源站地址配置
  - 回源协议选择
  - 回源头部设置

### 11. Cloudflare R2特有功能
- **自定义域名绑定**：
  - 添加自定义域名
  - 移除域名
  - 查看域名CNAME配置
