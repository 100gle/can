# 工具与辅助功能

## 功能描述
提供文件操作、开发调试等实用工具和高级功能。

## 核心需求

### 1. 文件完整性校验
**功能**：
- 计算本地文件的哈希值
- 计算S3中文件的哈希值
- 对比验证文件完整性

**支持的哈希算法**：
- MD5：快速计算，用于基础校验
- SHA256：安全性更高，用于数据完整性验证
- 其他：SHA1、SHA512等（可选）

**使用场景**：
1. 上传后验证：
   - 上传文件后，自动计算其哈希值
   - 与本地文件哈希对比
   - 确保上传过程未发生数据损坏

2. 批量验证：
   - 选择多个文件
   - 批量计算哈希值
   - 导出校验结果

3. 文件比对：
   - 对比两个文件是否相同
   - 识别重复文件

**实现**：
- 使用crypto库计算哈希
- 大文件分片计算（避免内存溢出）
- 显示进度条

### 2. 图片压缩/格式转换
**功能**：
- 在线压缩图片（减小文件大小）
- 格式转换（JPG↔PNG↔WebP等）
- 调整图片尺寸

**操作步骤**：
1. 选择或上传图片
2. 选择压缩级别/目标格式/尺寸
3. 预览效果
4. 下载转换后的文件或上传到S3

**参数配置**：
- 图片质量（1-100%）
- 目标宽度/高度
- 目标格式（JPEG/PNG/WebP/GIF）
- 保留元数据选项

**支持库**：
- ImageMagick或Sharp库（后端处理）
- 前端预览：Canvas或WebGL

### 3. 文件分片上传配置
**功能**：
- 配置分片大小（默认5MB，可调整）
- 配置并发上传分片数（默认4，可调整）
- 配置分片重试次数
- 配置分片上传超时时间

**配置项**：
```
分片大小：[1MB, 5MB, 10MB, 50MB]（预设）或自定义
并发分片数：[1, 2, 4, 8, 16]
重试次数：[1, 3, 5, 10]
超时时间：[30s, 60s, 300s]
```

**场景**：
- 网络不稳定时：减小分片大小、降低并发数、增加重试次数
- 网络良好时：增大分片大小、提高并发数、加快上传速度

### 4. CDN刷新集成
**仅在配置了CDN时可用**：

**支持的CDN**：
- Cloudflare
- 阿里云CDN
- 腾讯云CDN
- AWS CloudFront等

**功能**：
- 手动刷新CDN缓存
- 输入要刷新的URL或路径
- 支持通配符（如/path/*）
- 显示刷新结果和状态

**工作流程**：
1. 用户修改S3中的文件
2. 点击"刷新CDN"
3. 输入CDN域名和路径
4. 调用CDN API清除缓存
5. 显示刷新成功提示

**配置**：
- 需要在设置中配置CDN账户信息（API Key等）
- 保存CDN配置以便快速刷新
