# 工具与辅助功能

## 功能描述
提供文件操作、开发调试等实用工具和高级功能。

## 核心需求

### 1. 文件完整性校验
**功能**：
- 计算本地文件的哈希值
- 计算S3中文件的哈希值
- 对比验证文件完整性

**支持的哈希算法**：
- MD5：快速计算，用于基础校验
- SHA256：安全性更高，用于数据完整性验证
- 其他：SHA1、SHA512等（可选）

**使用场景**：
1. 上传后验证：
   - 上传文件后，自动计算其哈希值
   - 与本地文件哈希对比
   - 确保上传过程未发生数据损坏

2. 批量验证：
   - 选择多个文件
   - 批量计算哈希值
   - 导出校验结果

3. 文件比对：
   - 对比两个文件是否相同
   - 识别重复文件

**实现**：
- 使用crypto库计算哈希
- 大文件分片计算（避免内存溢出）
- 显示进度条

### 2. 分片上传配置
**功能**：
- 配置分片大小（默认5MB，可调整）
- 配置并发上传分片数（默认4，可调整）
- 配置分片重试次数
- 配置分片上传超时时间

**配置项**：
```
分片大小：[1MB, 5MB, 10MB, 50MB]（预设）或自定义
并发分片数：[1, 2, 4, 8, 16]
重试次数：[1, 3, 5, 10]
超时时间：[30s, 60s, 300s]
```

**场景**：
- 网络不稳定时：减小分片大小、降低并发数、增加重试次数
- 网络良好时：增大分片大小、提高并发数、加快上传速度
