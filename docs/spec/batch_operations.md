# 批量操作

## 功能描述
支持对多个对象进行批量修改和管理操作，提高工作效率。

## 核心需求

### 1. 批量设置访问权限
- 选择多个文件/文件夹
- 选择目标访问权限（Private/Public Read等）
- 显示将受影响的对象数量
- 确认并执行操作
- 显示批量操作进度
- 操作完成后显示成功/失败统计

### 2. 批量修改存储类型
- 选择多个文件
- 选择目标存储类型（标准/低频/归档等）
- 显示成本影响预估（可选）
- 确认并执行操作
- 显示操作进度和结果统计

### 3. 批量添加/删除标签
**添加标签**：
- 选择多个文件
- 输入要添加的标签（Key-Value对）
- 选择添加模式（覆盖现有/合并）
- 确认并执行

**删除标签**：
- 选择多个文件
- 选择要删除的标签Key
- 确认并执行

### 4. 批量设置元数据
- 选择多个文件
- 输入要设置的Metadata Key-Value对
- 选择设置模式（覆盖/合并）
- 确认并执行

### 5. 批量导出文件列表
导出选中文件的列表，包含以下选项：
- **导出格式**：CSV、JSON、TXT、Excel
- **包含信息**：选择要导出的字段
  - 文件名
  - 完整路径
  - 文件大小
  - 修改时间
  - 存储类型
  - ETag
  - 标签
  - 元数据
  - ACL
- **自定义**：自定义列顺序和内容

### 6. 批量操作流程
基础流程：
1. 用户多选文件（勾选复选框或Shift+Click）
2. 点击批量操作按钮
3. 选择具体操作（权限/标签/存储类型等）
4. 配置操作参数
5. 显示确认对话框（列出受影响对象）
6. 用户确认后执行
7. 实时显示操作进度
8. 操作完成后显示结果统计（成功数/失败数）

### 7. 批量操作控制
- **并发控制**：可配置批量操作的并发数
- **错误处理**：
  - 继续执行后续操作还是停止
  - 记录失败的对象和失败原因
- **取消操作**：支持取消正在进行的批量操作
- **重试失败项**：支持重新执行失败的操作

### 8. 操作历史和日志
- 记录所有批量操作
- 显示操作时间、类型、范围、结果
- 支持导出操作日志
- 支持恢复操作（部分支持，如删除操作不可恢复）
