# 界面导航与交互

## 功能描述
提供直观的导航体验和交互方式，包括侧边栏、统一文件浏览器、右键菜单和快捷功能。

## 核心需求

### 1. 侧边栏收起/展开
**功能**：
- 侧边栏默认展开状态（可配置）
- 点击图标或按钮收起/展开侧边栏
- 记住用户的侧边栏状态（localStorage）

**内容**：
- 账户列表和快速切换
- 设置入口

**响应式**：
- 移动设备上默认折叠（以节省空间）
- 点击汉堡菜单展开侧边栏

### 2. 统一文件浏览器（FileExplorer）
**核心设计**：
- 将存储桶和对象浏览合并为统一的文件系统视图
- 根目录显示所有存储桶（如同本地磁盘）
- 点击存储桶进入对象浏览
- 支持多级目录导航

**浏览器上下文**：
- 维护当前浏览层级（buckets 或 objects）
- 维护当前路径（面包屑）
- 独立的搜索和过滤状态

### 3. 面包屑导航
**功能**：
- 显示完整的导航路径：`根目录 / bucket-name / folder / subfolder`
- 支持点击面包屑快速跳转到任意层级
- 最后一项是当前位置（不可点击）
- "返回"按钮快速返回上一级

**增强**：
- 在面包屑上显示图标
- 支持快速返回根目录

### 4. 右键上下文菜单
**上下文菜单**：根据被右击的对象显示相关操作

**对存储桶右键**：
- 进入
- 设置
- 删除

**对文件右键**：
- 下载
- 复制链接
- 分享（预签名 URL）
- 删除

**对文件夹右键**：
- 进入
- 删除

**对空白区域右键**：
- 新建存储桶（仅在根目录）
- 上传文件
- 上传文件夹
- 刷新

### 5. 视图模式切换
- **网格视图（Grid）**：卡片形式，适合快速浏览
- **列表视图（List）**：表格形式，适合查看详情
- 视图状态在浏览器内保持一致
- 记住用户偏好

### 6. 内联搜索与过滤
**搜索**：
- 搜索框位于工具栏
- 实时过滤当前目录下的项目

**类型过滤**：
- 全部类型
- 文件夹
- 图片
- 文档
- 压缩包

**清除过滤**：
- 一键清除所有过滤条件

### 7. 通知和提示
**操作反馈**：
- 成功提示：绿色 Toast
- 错误提示：红色 Toast
- 警告提示：黄色 Toast
- 信息提示：蓝色 Toast

**显示位置**：
- 右下角或右上角
- 自动消失或用户关闭
- 提示应简洁清晰

### 8. 确认对话框
**删除确认**：
- 使用 AlertDialog 组件
- 显示将被删除的内容
- 提示不可恢复
- 用户确认后才执行删除

**新建存储桶对话框**：
- 使用 Dialog 组件
- 输入桶名称和区域
- 确认创建

### 9. 加载状态显示
- **全局加载指示**：页面加载时显示进度条或加载动画
- **局部加载指示**：组件加载时显示 spinner
- **无数据状态**：显示友好的空状态提示
- **过滤无结果**：显示"没有匹配的项目"并提供清除过滤按钮

### 10. 拖拽交互
- 拖拽文件到浏览区域触发上传
- 显示拖拽激活状态（边框高亮、背景遮罩）
- 释放后开始上传

### 11. 常用操作快捷入口
**工具栏**：
- 刷新按钮
- 上传按钮（仅在对象层级）
- 新建存储桶按钮（仅在根目录）
- 视图切换按钮
- 搜索框
- 类型过滤下拉
