# 界面导航与交互

## 功能描述
提供直观的导航体验和交互方式，包括侧边栏、标签页、历史记录和快捷功能。

## 核心需求

### 1. 侧边栏收起/展开
**功能**：
- 侧边栏默认展开状态（可配置）
- 点击图标或按钮收起/展开侧边栏
- 记住用户的侧边栏状态（localStorage）

**内容**：
- 账户列表和快速切换
- 存储桶导航
- 菜单项（如仪表板、设置等）

**响应式**：
- 移动设备上默认折叠（以节省空间）
- 点击汉堡菜单展开侧边栏（可选遮罩层）

### 2. 标签页管理
**功能**：
- 打开新标签页时创建标签
- 显示标签标题（如桶名）
- 标签页间快速切换
- 关闭标签页按钮
- 标签页拖拽排序（可选）

**标签页上下文**：
- 每个标签页独立维护浏览状态（当前目录、搜索过滤等）
- 标签页间不互相干扰
- 支持多账户的多标签页同时打开

**标签页管理菜单**（右键菜单）：
- 关闭当前标签页
- 关闭其他标签页
- 关闭所有标签页
- 刷新标签页

**标签页持久化**（可选）：
- 关闭应用前保存打开的标签页
- 重新打开应用时恢复标签页

### 3. 最近访问历史
**功能**：
- 记录用户访问过的存储桶和目录
- 显示访问时间
- 最多显示最近10-20项

**访问方式**：
- 侧边栏的"最近访问"下拉菜单
- 或独立的历史列表页
- 快速返回到之前访问的位置

**清空历史**：
- 支持删除单项
- 支持清空所有历史

### 4. 收藏夹/书签功能
**功能**：
- 用户可收藏常用的存储桶或目录
- 在侧边栏显示收藏夹列表
- 快速访问收藏的位置
- 管理收藏（添加、删除、重命名）

**操作**：
- 星标图标添加/移除收藏
- 收藏夹右键菜单：删除、重命名、排序等

### 5. 右键菜单
**上下文菜单**：根据被右击的对象显示相关操作

**对文件/文件夹右键**：
- 下载
- 复制
- 移动
- 删除
- 重命名
- 预览
- 查看属性
- 生成链接

**对存储桶右键**：
- 刷新
- 复制桶名
- 查看属性
- 访问控制
- 生成临时链接

### 6. 面包屑导航增强
**功能**：
- 显示完整的导航路径
- 支持点击面包屑快速跳转
- 最后一项是当前位置（不可点击）
- 路径过长时缩略显示（如超过5级）

**增强**：
- 在面包屑上显示图标
- 支持复制完整路径
- 支持路径编辑和快速跳转

### 7. 搜索栏位置
- **全局搜索**：在顶部或侧边栏显示搜索框
- **当前位置搜索**：在当前目录显示搜索框
- 搜索结果在下拉列表或新页面显示

### 8. 通知和提示
**操作反馈**：
- 成功提示：绿色Toast或Snackbar
- 错误提示：红色Toast或对话框
- 警告提示：黄色Toast
- 信息提示：蓝色Toast

**显示位置**：
- 右下角或右上角
- 自动消失或用户关闭
- 提示应简洁清晰

### 9. 加载状态显示
- **全局加载指示**：页面加载时显示进度条或加载动画
- **局部加载指示**：组件加载时显示skeleton或spinner
- **无数据状态**：显示友好的空状态提示

### 10. 返回按钮
- 在子页面显示"返回"按钮
- 支持浏览器后退功能（History API）
- 侧边栏菜单中显示当前活跃菜单项

### 11. 常用操作快捷入口
**功能栏**：
- 在顶部显示常用操作按钮（上传、下载、新建、删除等）
- 根据当前上下文显示/隐藏相关按钮
- 支持自定义操作栏顺序（可选）

## 交互模式

### 新建和编辑流程
- 点击按钮打开对话框或表单页
- 用户输入信息
- 确认时提交数据
- 显示成功/失败反馈

### 删除确认
- 弹出确认对话框
- 显示将被删除的内容摘要
- 提示不可恢复
- 用户确认后才执行删除

### 编辑流程
- 显示现有值
- 用户修改信息
- 自动检测变更
- 只有变更时才启用"保存"按钮
- 保存后显示成功反馈
