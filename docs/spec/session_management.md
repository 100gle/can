# 会话管理

## 功能描述
管理用户会话状态，包括记住上次使用的账户、多标签页支持和会话超时提醒。

## 核心需求

### 1. 会话持久化
- 记录上次使用的账户ID
- 应用启动时自动加载上次的账户
- 存储在本地持久化存储（localStorage或数据库）

### 2. 多账户标签页支持
- 支持同时打开多个账户的标签页或窗口
- 每个标签页独立维护当前的账户上下文
- 标签页之间不互相干扰

### 3. 会话超时管理
- 定义会话超时时间（建议30分钟）
- 监测用户活动（mouse/keyboard events）
- 超时时自动断开连接
- 显示超时警告对话框（提醒用户即将超时，可续期）

### 4. 会话信息
记录会话相关数据：
- 账户ID
- 连接时间
- 最后活动时间
- 超时时间配置
