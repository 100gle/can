# 对象访问链接生成

## 功能描述
生成对象的公共访问URL和预签名临时URL，支持自定义配置和二维码生成。

## 核心需求

### 1. 公共访问URL
- 生成可公开访问的直接链接
- URL格式：`https://[bucket-domain]/[object-key]`
- 仅在对象或桶为公开读时有效
- 支持复制链接到剪贴板
- 显示链接有效性状态（可访问/不可访问提示）

### 2. 预签名临时URL
基于S3 Presigned URL机制：

**配置参数**：
- 过期时间：
  - 预设选项（1小时、1天、7天、30天等）
  - 自定义时间（输入秒数）
- 允许的HTTP方法：
  - GET（下载）
  - PUT（上传）
  - HEAD（检查）
  - DELETE（删除）
  - 支持多选
- 自定义响应头：
  - Content-Disposition（指定下载文件名）
  - Content-Type（指定内容类型）
  - Cache-Control（缓存控制）

**生成流程**：
1. 用户选择配置参数
2. 调用S3签名生成API
3. 返回预签名URL
4. 显示URL和配置信息
5. 支持复制到剪贴板
6. 显示过期时间

### 3. 链接复制到剪贴板
- 一键复制按钮
- 显示复制成功反馈
- 支持复制多个格式（URL、Markdown、HTML等）

### 4. 二维码生成
- 生成预签名URL的二维码
- 支持自定义二维码大小和纠错级别
- 显示二维码预览
- 支持下载二维码图片
- 用于移动端快速访问

### 5. 链接管理和历史
- 记录生成的预签名链接历史
- 显示各链接的创建时间和过期时间
- 支持快速复制历史链接
- 支持删除历史记录（可选）

### 6. 链接分享
- 显示链接及其配置信息
- 支持发送链接（集成邮件/消息服务，可选）
- 显示链接安全提示（仅对需要授权的操作）

## 数据流
1. 用户选择对象
2. 点击"生成链接"或"生成预签名URL"
3. 显示配置对话框
4. 用户配置参数
5. 调用S3 API生成预签名URL
6. 显示结果（URL、二维码等）
7. 用户复制或分享链接
