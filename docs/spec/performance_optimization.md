# 性能优化

## 功能描述
提供性能相关的配置和优化选项，包括并发控制、缓存策略和离线功能。

## 核心需求

### 1. 并发上传/下载数量配置
**功能**：
- 设置同时上传的文件数（默认4）
- 设置同时下载的文件数（默认4）
- 范围：1-16（可根据实际调整）

**配置位置**：
- 设置 → 性能 → 传输配置

**参数配置**：
```
上传并发数: [1, 2, 4, 8, 16]
下载并发数: [1, 2, 4, 8, 16]
单个连接超时: [30s, 60s, 120s, 300s]
总超时: [5分钟, 10分钟, 30分钟, 无限]
```

**性能影响**：
- 并发数↑ = 更快的传输但更多内存和CPU使用
- 并发数↓ = 更慢但更稳定，网络条件差时推荐

**推荐值**：
- 网络很好：8-16
- 网络一般：4-8
- 网络差/不稳定：1-2

### 2. 分片大小配置
**功能**：
- 配置大文件上传时的分片大小
- 默认：5MB
- 范围：1MB - 100MB

**参数**：
```
分片大小: [1MB, 5MB, 10MB, 25MB, 50MB, 100MB]
```

**性能考虑**：
- 分片小 = 更多请求和开销，但网络不稳定时恢复更快
- 分片大 = 更少请求，但网络中断需要重新传输更多数据

**推荐值**：
- 网络很好：25-50MB
- 网络一般：5-10MB
- 网络差：1-5MB

### 3. 缓存策略设置
**缓存类型**：

**对象列表缓存**：
- 启用/禁用列表缓存
- 缓存过期时间（默认5分钟）
- 最多缓存多少个列表（防止内存溢出）

**统计数据缓存**：
- 启用/禁用统计数据缓存
- 缓存过期时间（默认30分钟）
- 手动刷新按钮

**图片缩略图缓存**：
- 启用/禁用缩略图缓存
- 缓存大小限制（如100MB）
- 清空缓存按钮

**配置**：
```json
{
  "cache": {
    "list_objects": {
      "enabled": true,
      "ttl_seconds": 300,
      "max_items": 10000
    },
    "statistics": {
      "enabled": true,
      "ttl_seconds": 1800
    },
    "thumbnails": {
      "enabled": true,
      "size_limit_mb": 100
    }
  }
}
```

**缓存管理**：
- 显示当前缓存大小
- 清空缓存按钮
- 禁用缓存选项（用于调试）

### 4. 连接池管理
**功能**：
- 配置HTTP连接池大小
- 默认：10个连接
- 范围：1-100

**参数**：
```
最大连接数: [1, 5, 10, 20, 50, 100]
连接保活: [启用/禁用]
连接重用: [启用/禁用]
```

**TCP保活配置**：
- Keep-alive间隔（默认30秒）
- Keep-alive超时（默认5分钟）

**性能影响**：
- 连接数更多 = 更高的并发但更多资源
- 连接重用 = 减少连接建立开销

### 5. 列表分页配置
**功能**：
- 设置一次列表加载的对象数（默认1000）
- 范围：100-10000
- 根据网络条件调整

**参数**：
```
单页对象数: [100, 500, 1000, 2000, 5000, 10000]
启用虚拟滚动: [启用/禁用]（对大列表性能优化）
列表预加载: [启用/禁用]（预加载下一页）
```

### 6. 内存优化
**功能**：
- 显示当前应用内存使用情况
- 设置内存使用限制（触发警告）
- 内存清理工具

**内存优化选项**：
- 限制缓存大小
- 定期清理过期缓存
- 垃圾回收建议
- 关闭不需要的功能（如实时监控）

### 7. 网络优化
**功能**：
- 启用/禁用请求压缩（gzip）
- 启用/禁用HTTP持久连接
- DNS缓存配置

**参数**：
```
启用请求压缩: [是/否]
启用HTTP2: [是/否]（如支持）
DNS预解析: [是/否]
DNS缓存时间: [1h, 6h, 24h]
```

### 8. 离线功能
**功能**：
- 启用/禁用离线模式
- 离线时缓存最近访问的数据
- 网络恢复后自动同步

**离线队列**：
- 用户在离线时进行的操作（上传、删除等）存入队列
- 网络恢复后自动执行
- 显示待同步操作列表

**离线缓存**：
- 缓存最近查看的文件列表
- 缓存文件预览内容
- 支持离线浏览（读操作）

**配置**：
```
启用离线支持: [是/否]
缓存大小: [10MB, 50MB, 100MB, 500MB]
网络检查间隔: [10s, 30s, 60s]
自动同步: [是/否]
```

**离线状态指示**：
- 在UI中显示离线状态
- 禁用需要网络的功能（上传、下载等）
- 显示待同步操作数

### 9. 性能监控仪表板
**显示指标**：
- CPU使用率（应用占用）
- 内存使用（当前/总大小）
- 网络速度
- API响应时间（平均值）
- 缓存命中率
- 活跃连接数

**图表**：
- 性能指标的时间序列图
- 资源使用趋势

### 10. 性能优化建议
**自动分析和建议**：
- "内存使用超过阈值，建议清空缓存"
- "并发数设置过高，可能导致连接超时，建议降至8"
- "网络速度较慢，建议减小分片大小"
- "启用离线模式有助于离线使用，但会增加内存使用"
