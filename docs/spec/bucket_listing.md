# 存储桶列表

## 功能描述
存储桶以文件夹形式展示在统一文件浏览器的根目录中，用户可以像浏览本地磁盘一样浏览存储桶。

## 核心需求

### 1. 存储桶信息展示
在统一文件浏览器根目录中显示以下信息：
- 桶名称
- 所在区域（Region）
- 创建时间
- 对象数量（如服务商API支持）
- 总容量/使用空间（如服务商API支持）

### 2. 列表/网格视图
- **网格视图**：存储桶以硬盘图标+名称卡片形式展示
- **列表视图**：表格形式显示详细信息
- 视图模式与对象浏览保持一致

### 3. 搜索和过滤
- **桶名称搜索**：在统一搜索框中实时搜索
- **搜索结果实时更新**

### 4. 存储桶操作
**通过右键菜单操作**：
- 进入存储桶
- 存储桶设置
- 删除存储桶

**通过空白区域右键菜单**：
- 新建存储桶

**通过工具栏按钮**：
- 刷新列表
- 新建存储桶

### 5. 新建存储桶对话框
- 输入桶名称
- 输入区域（Region）
- 确认创建

### 6. 删除存储桶
- 弹出确认对话框
- 提示不可恢复
- 确认后执行删除

### 7. 列表加载状态
- 显示加载中状态（spinner）
- 处理加载失败情况（错误提示）
- 显示空列表状态（友好提示）

## 数据获取
- 调用S3 API（ListBuckets）获取列表
- 实现数据缓存策略以优化性能
