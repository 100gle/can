# 存储桶列表

## 功能描述
显示和管理S3兼容存储中的所有存储桶，包括列表展示、排序、搜索和过滤功能。

## 核心需求

### 1. 存储桶信息展示
列表需显示以下信息：
- 桶名称
- 所在区域（Region）
- 创建时间
- 对象数量（如服务商API支持）
- 总容量/使用空间（如服务商API支持）

### 2. 列表排序
支持按以下维度排序：
- 桶名称（A-Z或Z-A）
- 创建时间（新到旧或旧到新）
- 存储空间大小（大到小或小到大）
- 对象数量

### 3. 搜索和过滤
- **桶名称搜索**：前缀搜索或模糊搜索
- **区域过滤**：按指定区域筛选桶
- **搜索结果实时更新**

### 4. 列表操作
- 刷新列表（重新从服务商获取数据）
- 选中桶进入详情页或进行操作

### 5. 列表加载状态
- 显示加载中状态
- 处理加载失败情况
- 显示空列表状态

## 数据获取
- 调用S3 API（ListBuckets）获取列表
- 对于对象数量和容量，需逐个查询桶的统计信息（可异步加载）
- 实现数据缓存策略以优化性能
