# 成本分析

## 功能描述
根据使用情况和云服务商的价格体系计算成本，并提供成本趋势分析和优化建议。

## 核心需求

### 1. 成本构成分析
**存储成本**：
- 标准存储成本 = 标准存储容量 × 标准存储单价
- 低频存储成本 = 低频存储容量 × 低频存储单价
- 归档存储成本 = 归档存储容量 × 归档存储单价
- 各类型存储成本占比

**流量成本**：
- 下行流量成本（最主要）= 下行流量 × 单价
- 上行流量成本（通常免费或很低）
- 跨域流量成本（如有）
- CDN费用（如使用）

**请求成本**：
- GET请求成本 = GET请求数 × 单价
- PUT请求成本 = PUT请求数 × 单价
- 其他请求成本

**其他成本**：
- 数据检索成本（归档存储）
- API调用成本
- 监控和日志费用

### 2. 服务商成本配置
应用程序需要维护各服务商的定价表：

**AWS S3**（示例，实际需从AWS获取）：
- 标准存储：按地区变化（如us-east-1为$0.023/GB）
- 低频存储：$0.0125/GB
- 冰川存储：$0.004/GB
- 下行流量：$0.09/GB（互联网）
- GET请求：$0.0004/1000请求
- PUT请求：$0.005/1000请求

**阿里云OSS**（示例）：
- 标准存储：按存储量分档
- 低频存储：$0.01/GB
- 下行流量：按区域和流量大小分档

**腾讯云COS**（示例）：
- 标准存储：$0.015/GB
- 低频存储：$0.01/GB
- 归档存储：$0.002/GB

**Cloudflare R2**：
- 存储：$0.015/GB
- 上传：免费
- 下载：前10GB免费，之后$0.015/GB

### 3. 成本估算显示
**当前成本**：
- 本月累计成本
- 各类型成本分项
- 成本环比（本月vs上月）

**成本预估**：
- 按当前速率估算月度成本
- 按当前速率估算年度成本

**成本详情表格**：
| 成本类型 | 数量 | 单价 | 费用 | 占比 |
|---------|------|------|------|------|
| 存储-标准 | 100GB | $0.023 | $2.30 | 30% |
| 下行流量 | 50GB | $0.09 | $4.50 | 60% |
| GET请求 | 10000 | $0.0004 | $0.40 | 5% |
| ...     | ...  | ...  | ...  | ... |

### 4. 成本趋势分析
**时间周期**：
- 每日成本
- 每周成本
- 每月成本
- 自定义周期

**趋势图表**：
- 折线图：显示成本随时间变化
- 堆积面积图：显示各成本类型的占比变化
- 对比分析：本月vs上月、本年vs去年等

### 5. 成本优化建议
基于使用模式提供优化建议：

**存储优化**：
- "建议将30天未访问的100GB文件转移到低频存储，可节省50%存储费用"
- "归档存储成本最低，建议将1年未访问的数据转移到归档"

**流量优化**：
- "下行流量费用占比60%，建议使用CDN加速降低流量费用"
- "跨域流量成本较高，建议部署更接近用户的副本"

**请求优化**：
- "GET请求数较多，建议增加缓存策略"
- "考虑使用List Multipart Uploads等批量API降低请求数"

**生命周期建议**：
- "配置生命周期规则自动转移冷数据"
- "设置对象过期删除以节省存储成本"

### 6. 成本对比
- **服务商对比**：同样的使用量在不同服务商的成本对比
- **存储位置对比**：相同数据在不同地区的存储成本对比
- **存储类型对比**：各存储类型的成本-性能权衡

### 7. 成本告警
- 设置月度成本上限告警
- 设置日均成本异常告警
- 设置某类成本占比过高告警
- 告警通知

### 8. 成本报告
- 生成周/月/年度成本报告
- 报告包含成本分析、优化建议等
- 导出为PDF/Excel
- 邮件发送报告

### 9. 应用内成本配置
**定价表维护**：
- 缓存定价表（定期更新）
- 支持手动上传最新定价
- 验证定价合理性

**计费周期**：
- 显示账单周期
- 如果是预付费则显示剩余额度

## 数据来源
1. 从存储统计获取：使用空间、对象数量、存储类型分布
2. 从流量监控获取：流量数据、请求数据、错误统计
3. 从服务商定价表获取：各项成本单价
4. 计算：成本 = 数据 × 单价
