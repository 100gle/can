# 存储统计

## 功能描述
提供存储空间使用情况的统计和分析，包括按桶、存储类型的分布以及趋势分析。

## 核心需求

### 1. 按存储桶统计
显示各存储桶的存储情况：
- 桶名称
- 使用空间（总大小）
- 对象数量
- 平均文件大小
- 占比（百分比和饼图）
- 排序选项（按大小、对象数等）

### 2. 对象数量统计
- 各桶的对象总数
- 对象类型分布（通过扩展名/MIME type分类）
- 统计结果表格或图表展示

### 3. 存储类型分布
按存储类型统计：
- 标准存储：大小、对象数、占比
- 低频存储：大小、对象数、占比
- 归档存储：大小、对象数、占比
- 其他服务商特定类型

显示形式：
- 表格视图
- 堆积柱状图
- 分段饼图

### 4. 按时间的趋势图表
**时间范围选择**：
- 预设范围（最近7天、30天、90天等）
- 自定义日期范围

**趋势指标**：
- 总存储空间趋势
- 对象数量趋势
- 各存储类型的占比变化
- 存储增长速度

**图表类型**：
- 折线图（显示趋势）
- 柱状图（对比周期变化）
- 堆积面积图（显示各类型占比变化）

### 5. 数据统计范围
- **全局统计**：所有账户、所有桶
- **账户统计**：指定账户的所有桶
- **桶统计**：指定桶的详细数据

### 6. 数据刷新和缓存
- 显示数据最后更新时间
- 提供手动刷新按钮
- 可配置自动刷新间隔（可选）
- 实现数据缓存以优化性能

### 7. 统计数据导出
- **导出为CSV**：包含所有统计指标
- **导出为JSON**：完整数据结构
- **导出为PDF/图片**：图表快照

### 8. 对比分析（可选）
- 按时间对比（如本月vs上月）
- 按桶对比
- 显示增长率或变化量

### 9. 存储容量告警（可选）
- 设置使用量告警阈值
- 接近限制时发送通知
- 记录告警历史

## 数据获取
- 使用S3 ListObjects API获取对象列表（可能需要逐个扫描）
- 从对象元数据计算统计数据
- 对于CloudWatch或其他监控API支持的服务，可直接查询

## 数据计算
```
总容量 = 所有对象大小之和
对象数量 = ListObjects返回对象数
平均大小 = 总容量 / 对象数量
存储类型分布 = 按StorageClass分组聚合
```
