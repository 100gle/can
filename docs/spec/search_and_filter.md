# 搜索与过滤

## 功能描述
提供全局和桶内搜索功能，以及基于多个维度的高级过滤和搜索结果导出。

## 核心需求

### 1. 全局搜索
- 跨所有存储桶搜索对象
- 输入搜索关键词
- 实时显示搜索结果
- 结果分类显示（按桶分组）
- 支持结果排序

### 2. 当前桶内搜索
- 在当前选中的桶内搜索
- 基于对象Key前缀搜索
- 支持模糊搜索（如支持）
- 实时显示搜索结果

### 3. 高级过滤
支持以下过滤条件：

**文件大小范围**：
- 最小大小（字节）
- 最大大小（字节）
- 预设范围选项（如"小于1MB"、"1-10MB"等）

**修改时间范围**：
- 开始时间（日期选择器）
- 结束时间（日期选择器）
- 预设选项（如"最近24小时"、"最近7天"等）

**文件类型**：
- 多选文件类型（图片、文档、视频、音频等）
- 支持按MIME type或文件扩展名

**存储类型**：
- 选择特定的存储类型（标准、低频、归档等）

**标签过滤**：
- 按标签Key-Value对过滤
- 支持多标签AND/OR逻辑（可选）

### 4. 过滤条件组合
- 支持多个过滤条件同时使用
- 动态更新搜索结果
- 显示当前活跃的过滤条件
- 支持一键清除所有过滤

### 5. 搜索结果显示
- 列表视图显示搜索结果
- 显示文件基本信息（名称、大小、修改时间等）
- 支持结果排序
- 高亮显示匹配关键词
- 每页显示数量可配置

### 6. 搜索结果导出
- **导出为CSV**：包含搜索结果的所有列信息
- **导出为JSON**：包含完整的对象元数据
- **导出为文本列表**：仅文件路径，每行一个
- 自定义导出内容（选择包含的列）

### 7. 搜索性能优化
- 显示搜索进度
- 支持搜索超时处理
- 大结果集分页加载

### 8. 保存搜索条件
- 支持保存常用搜索/过滤条件
- 快速加载保存的搜索
- 删除保存的搜索
- 导出/导入搜索条件（可选）

## 数据流
1. 用户输入搜索关键词或设置过滤条件
2. 实时调用S3 ListObjects API（可能分页）
3. 应用过滤逻辑（在客户端或服务端）
4. 显示搜索结果
5. 用户可进一步操作结果（导出、打开等）

## 实现进度（2025-02）

- ✅ **核心搜索服务**：`internal/search` 包提供了高性能的对象搜索能力。
- ✅ **多维度过滤**：`ApplyFilters` 函数实现了基于大小、时间、文件类型、标签的内存级过滤。
- ✅ **跨桶搜索**：支持并发扫描多个存储桶（`resolveBuckets`）聚合结果。
- ✅ **结果导出**：内置 CSV/JSON 导出器，支持流式写入。
- ✅ **性能控制**：通过 `maxInspect` 和 `pageLimit` 防止内存溢出，支持 `ListObjects` 分页扫描。
- ✅ **前端体验**：`src/components/search/search-panel.tsx` 已提供高级过滤、分页、导出及保存查询的完整交互；`searchStore` 负责状态、导出和保存逻辑。
- 🚧 **待完善功能**：
    - 自定义导出列仍为固定模板。
    - 搜索历史（与保存的查询不同）尚未实现。
    - 模糊搜索目前是简单的 substring match (`strings.Contains`)。
