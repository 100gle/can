# 文件下载

## 功能描述
支持单文件下载、批量下载、文件夹下载、断点续传和预签名链接生成等功能。

## 核心需求

### 1. 下载方式
- **单文件下载**：直接下载指定文件
- **批量下载**：选择多个文件，打包为ZIP后下载
- **文件夹下载**：选择目录，递归下载所有文件并保持结构

### 2. 断点续传
- 支持HTTP Range请求
- 记录已下载字节数
- 支持暂停和恢复下载
- 下载中断后可续传
- 本地存储下载进度

### 3. 下载队列管理
- 维护下载任务队列
- 并发下载控制（默认并发数，可配置）
- 显示队列中各任务的状态
- 支持任务优先级调整（可选）
- 队列持久化（应用关闭后恢复）

### 4. 下载进度显示
- 总体下载进度条
- 单个文件下载进度
- 下载速度显示（KB/s或MB/s）
- 预计剩余时间
- 已下载/总大小显示

### 5. 预签名URL生成
- 生成临时下载链接（预签名URL）
- 配置链接过期时间（可设置如1小时、1天、7天等）
- 配置下载时的文件名（Content-Disposition）
- 支持下载链接复制到剪贴板
- 可生成QR码用于移动端访问

### 6. 批量下载的ZIP处理
- 自动创建ZIP文件
- 保持原目录结构
- 支持自定义ZIP文件名
- 显示ZIP生成进度

### 7. 下载验证
- 校验下载文件完整性（可选，使用ETag或MD5）
- 显示验证结果

### 8. 下载目标位置
- 自定义下载文件夹位置
- 处理文件命名冲突（覆盖/重命名）
- 显示下载完成通知

## 数据流
1. 用户选择下载文件/文件夹
2. 选择下载参数（如预签名URL的过期时间）
3. 添加到下载队列
4. 建立HTTP连接并开始下载
5. 跟踪下载进度
6. 处理完成或失败
