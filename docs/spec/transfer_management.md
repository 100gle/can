# 传输管理

## 功能描述
管理上传和下载任务，包括任务列表、状态跟踪、暂停/恢复、速度限制、历史记录等功能。

## 核心需求

### 1. 传输任务列表
显示所有上传和下载任务：

**任务信息**：
- 任务ID
- 文件名和路径
- 操作类型（上传/下载）
- 源位置和目标位置
- 文件大小
- 当前进度（已传输/总大小，百分比）
- 传输速度（KB/s或MB/s）
- 预计剩余时间
- 当前状态（进行中/暂停/完成/失败）
- 开始时间和完成时间

### 2. 任务状态实时更新
- 使用WebSocket或轮询实时更新进度
- 实时显示速度和剩余时间的变化
- 任务完成/失败时发送通知

### 3. 暂停/恢复任务
- 对进行中的任务点击"暂停"
- 显示任务状态为"已暂停"
- 对暂停的任务点击"恢复"继续传输
- 支持批量暂停/恢复

### 4. 取消任务
- 取消进行中或暂停中的任务
- 显示确认对话框
- 清理已传输的临时文件
- 支持批量取消

### 5. 传输速度限制
- **全局速度限制**：设置所有传输的总带宽限制
- **单个任务速度限制**：为特定任务设置速度上限
- 支持KBps/MBps设置
- 0 = 不限制

### 6. 传输历史记录
显示已完成和已失败的传输任务：
- 任务详情（文件名、大小、耗时）
- 完成时间
- 成功/失败状态
- 失败原因（如有）
- 支持按状态、时间等过滤历史
- 支持清空历史（可选）

### 7. 失败任务处理
- 显示失败原因（网络错误、权限错误等）
- 提供"重试"按钮
- 自动重试配置（重试次数、延迟）
- 支持重试所有失败任务
- 保留失败日志

### 8. 传输统计
- 今日/本周/本月传输统计
- 总传输数据量
- 平均传输速度
- 成功率

### 9. 任务优先级
- 调整队列中任务的执行顺序（可选）
- 设置优先级（高/中/低）
- 优先级高的任务优先执行

### 10. 离线传输
- 网络中断时暂停传输
- 网络恢复后自动恢复
- 显示离线状态提示

## 数据结构
```
传输任务 {
  id: string
  type: 'upload' | 'download'
  fileName: string
  filePath: string
  bucketName: string
  totalSize: number
  transferredSize: number
  startTime: timestamp
  endTime?: timestamp
  status: 'pending' | 'uploading' | 'downloading' | 'paused' | 'completed' | 'failed'
  speed: number
  eta: number
  progress: number (0-100)
  error?: string
}
```

## 实现进度（2025-12）

- ✅ **核心传输引擎**：基于 `internal/transfer` 包实现了多 Worker 并发传输模型。
- ✅ **队列管理**：支持任务排队、持久化存储（SQLite/Memory）、以及应用重启后的任务恢复（`restorePendingTasks`）。
- ✅ **状态控制**：实现了完整的 暂停/恢复/取消 状态机，支持优雅停止正在进行的传输。
- ✅ **进度追踪**：基于 `progressReader` 实现了字节级进度回调，支持实时速度计算和剩余时间估算。
- ✅ **持久化**：所有任务状态变更实时写入存储层（`store.Update`），确保意外退出不丢失任务状态。
- ✅ **传输队列 UI**：`transfers-page.tsx` 采用 Card 组件包装任务列表，与其他页面风格统一，包含 CardHeader（标题+任务数）和 CardContent（表格/空状态）。
- ✅ **PageHeader 集成**：传输管理页面使用统一的 `PageHeader` 组件，支持返回导航、速度限制设置和清理已完成按钮。
- ✅ **速度限制**：后端 `RateLimiter` 与 Frontend `setGlobalSpeedLimit` 已集成。
- 🚧 **待完善功能**：
    - 优先级队列目前为 FIFO。
