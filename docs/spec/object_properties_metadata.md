# 对象属性与元数据

## 功能描述
查看和编辑对象的详细属性、元数据、标签，以及管理版本控制等功能。

## 核心需求

### 1. 文件详细信息
显示以下信息：
- 文件名和完整Key路径
- 文件大小（字节和格式化显示）
- 创建时间
- 最后修改时间
- 存储类型（标准/低频/归档等）
- ETag（文件指纹）
- Content-Type
- 当前访问权限（ACL）
- 版本ID（如启用版本控制）
- 加密状态
- 元数据列表

### 2. 元数据编辑
- 查看所有自定义Metadata Key-Value对
- 添加新的Metadata项
- 编辑现有Metadata值
- 删除Metadata项
- 保存修改（调用S3 CopyObject）

### 3. 标签管理
- 查看所有标签
- 添加新标签（Key-Value对）
- 编辑标签
- 删除标签
- 批量添加标签（可选）

### 4. 修改存储类型
- 选择新的存储类型
- 查看类型变更的影响（如成本变化）
- 确认并应用修改

### 5. 修改访问权限（ACL）
- 查看当前ACL
- 修改为预设权限（Private/Public Read等）
- 自定义ACL规则
- 应用修改

### 6. 版本控制
**仅在桶启用版本控制时可用**：

- **查看版本历史**：
  - 列出对象的所有版本
  - 显示版本ID、修改时间、大小
  - 标记当前版本（Latest）

- **恢复历史版本**：
  - 选择要恢复的版本
  - 确认恢复操作
  - 恢复后成为新版本（版本ID不变）

- **永久删除版本**：
  - 选择要删除的特定版本
  - 确认删除
  - 该版本彻底删除，不可恢复
  - 当前版本不能删除（除非删除对象）

### 7. AWS特有功能
- **对象锁定（Object Lock）**：
  - 查看锁定状态
  - 配置保留模式（Governance/Compliance）
  - 设置保留截止时间
  - 配置法律保留

### 8. 阿里云OSS特有功能
- **软链接（Symlink）管理**：
  - 查看是否为软链接
  - 创建软链接（指向另一对象）
  - 删除软链接

### 9. 批量属性修改
- 支持批量修改元数据
- 支持批量修改存储类型
- 支持批量修改ACL
- 支持批量添加/删除标签
