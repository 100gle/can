# 多账户配置管理

## 功能描述
支持添加、编辑、删除多个S3兼容存储账户配置，并提供配置管理、测试、导入/导出等功能。

## 核心需求

### 1. 账户信息结构
每个账户需要存储以下信息：
- 账户名称（自定义标识）
- 服务商类型（AWS S3 / 阿里云 OSS / 腾讯云 COS / Cloudflare R2）
- Endpoint（访问地址）
- Access Key ID
- Secret Access Key
- 默认区域（Region）
- SSL使用标识（boolean）
- 自定义端口（可选，integer）

### 2. 账户操作
- **添加账户**：表单填写所有账户信息
- **编辑账户**：修改现有账户配置
- **删除账户**：移除账户配置

### 3. 账户本地存储
- 实现本地加密存储机制（SQLite + GORM ORM）
- 使用对称加密（如AES-256）保护敏感信息（Access Keys）
- 定义加密密钥管理方案
- 支持通过环境变量切换数据库驱动（`sqlite` / `memory`）和 DSN

### 4. 配置导入/导出
- **导出功能**：将账户配置导出为加密文件格式
- **导入功能**：从加密文件导入账户配置
- 定义导出文件格式和加密标准

### 5. 账户快速切换
- 实现下拉菜单或侧边栏账户列表
- 快速切换当前活跃账户
- 显示当前激活账户标识

### 6. 连接测试
- **测试连接功能**：验证账户配置是否有效
- 通过连接测试调用云服务商API（如List Buckets）
- 返回成功/失败和详细错误信息

## 实现进度（2025-02）

- ✅ 多账户列表与快速切换：Go 服务通过 `accounts.Service` 聚合读写，前端提供侧边栏切换与连接状态展示。
- ✅ 本地加密与 Stub Dialer：敏感凭证使用可配置 AES-256/Noop 加密，默认提供连接测试的 Stub Dialer，便于后续接入真实厂商 SDK。
- ✅ 账户 CRUD：新增/编辑/删除流程已通过桌面端抽屉表单串联，支持必填校验、危险操作确认及错误提示。
- ✅ 会话恢复：活跃账户状态在 Go 侧持久于 Service 实例，并在应用启动时自动回填。
- ✅ 导入/导出：通过 Wails 文件对话框生成/读取 .canx 加密文件，支持批量恢复账户配置；SQLite ORM 已上线，默认将账户保存到 `%USER_CONFIG%/can/accounts.db`，并可通过 `CAN_DB_DRIVER` / `CAN_DB_DSN` 切换存储策略。
