# 多账户配置管理

## 功能描述
支持添加、编辑、删除多个S3兼容存储账户配置，并提供配置管理、测试、导入/导出等功能。

## 核心需求

### 1. 账户信息结构
每个账户需要存储以下信息：
- 账户名称（自定义标识）
- 服务商类型（AWS S3 / 阿里云 OSS / 腾讯云 COS / Cloudflare R2）
- Endpoint（访问地址）
- Access Key ID
- Secret Access Key
- 默认区域（Region）
- SSL使用标识（boolean）
- 自定义端口（可选，integer）

### 2. 账户操作
- **添加账户**：表单填写所有账户信息
- **编辑账户**：修改现有账户配置
- **删除账户**：移除账户配置

### 3. 账户本地存储
- 实现本地加密存储机制
- 使用对称加密（如AES-256）保护敏感信息（Access Keys）
- 定义加密密钥管理方案

### 4. 配置导入/导出
- **导出功能**：将账户配置导出为加密文件格式
- **导入功能**：从加密文件导入账户配置
- 定义导出文件格式和加密标准

### 5. 账户快速切换
- 实现下拉菜单或侧边栏账户列表
- 快速切换当前活跃账户
- 显示当前激活账户标识

### 6. 连接测试
- **测试连接功能**：验证账户配置是否有效
- 通过连接测试调用云服务商API（如List Buckets）
- 返回成功/失败和详细错误信息
