# 存储桶基础操作

## 功能描述
支持创建、删除、清空存储桶等基础操作，并根据服务商提供特定选项。

## 核心需求

### 1. 创建存储桶
**通用参数**：
- 桶名称
- 区域/Region
- 访问权限（私有/公共读等）

**服务商特有参数**：
- **阿里云OSS**：存储类型选择（标准/低频/归档/冷归档等）
- **腾讯云COS**：多AZ配置选项（单AZ/多AZ）

**操作流程**：
1. 验证桶名称有效性（遵循S3命名规则）
2. 调用对应服务商API创建桶
3. 返回创建结果

### 2. 删除存储桶
- 显示删除确认对话框
- 检查桶是否为空（需先删除所有对象）
- 若桶不为空，提示用户清空桶或清除所有对象
- 调用API删除桶
- 返回删除结果

### 3. 清空存储桶
- 显示清空确认对话框（警告：此操作不可恢复）
- 批量删除桶内所有对象
- 处理版本化对象（如启用版本控制）
- 显示清空进度
- 完成后刷新列表

### 4. 刷新存储桶列表
- 重新从服务商获取最新数据
- 更新UI显示
