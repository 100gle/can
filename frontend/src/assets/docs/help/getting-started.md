# Quick Start · 快速入门

Welcome to **CAN Object Studio**. Follow this guided path to complete your first sync in a few minutes.

欢迎使用 **CAN Object Studio**。按照以下步骤，几分钟内完成首次文件同步。

## 1. Connect an Account 连接账户

- Open the home hub and click **“新建账户 / New Account”**  
- Provide endpoint, keys, region, and whether SSL is required  
- Click **“测试连接 / Test Connection”** to verify credentials before saving

## 2. Browse Buckets 浏览存储桶

- 进入任意账户的仪表盘，左侧显示其全部 Bucket  
- 支持搜索、快速过滤以及右键菜单操作  
- 鼠标悬停可看到区域、版本化状态等关键信息

## 3. Upload & Download 文件上传下载

- 拖拽文件/文件夹到对象浏览器，或使用工具栏的 **上传** 按钮  
- 任务会自动进入传输队列，断点续传与限速默认启用  
- 需要下载时，可批量选择对象后点击 **下载** 或生成预签名 URL

## 4. Configure Bucket Policies 桶配置

- 打开 **“桶设置 / Bucket Settings”** 页面  
- 在版本控制、CORS、ACL、Referer 白名单之间切换  
- 对不支持的提供商会自动禁用相关项，避免误操作

## 5. Keep Everything Safe 安全与备份

- 使用 **“系统设置 / Settings”** → “备份与还原” 导出加密配置  
- 安全中心提供最小权限提示、MFA Delete 状态、公共访问检测  
- 定期检查更新，获取最新的安全补丁和功能

Need help later? Use the **Help & Support** page anytime to revisit these steps, access FAQs, or contact the team.
